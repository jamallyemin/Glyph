# Glyph
a browser puzzle game about finding the hidden rule. every row and column of a 3x3 grid follows a pattern across shape, color, and count. work out what belongs in the missing cell.

current features

* 3x3 matrix puzzles where each attribute forms its own hidden latin square
* 4 difficulty tiers (color only, then shape, then count, then full grid)
* endless mode with 3 lives and a streak counter
* daily challenge, the same 5 seeded puzzles for everyone each day
* wordle-style shareable emoji result for the daily
* per-round timer with a saved fastest-solve record
* hint button that reveals one attribute (costs your streak)
* progress bar to the next tier
* confetti on new best streaks and tier-ups
* best streak, best time, and daily results saved in the browser
* fully responsive layout
* no backend, no login

tech stack

* html5
* css3 (flexbox, grid)
* vanilla javascript
* google fonts (space grotesk, ibm plex mono)
